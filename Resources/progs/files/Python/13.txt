2. Define a class to represent compound data.

Program: 
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    regno: str
    score: float

# Creating an instance of the Student class
p = Student("Gopika", "RA243241050006", 98.6)

# Printing the instance
print(p)
 
OUTPUT:
Student(name='Gopika', regno='RA243241050006', score=98.6)
