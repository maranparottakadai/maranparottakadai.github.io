Aim : To Implement Socket method  . 

Procedure: 
1. Start 
2. Import the socket module. 
3. Create a client socket using socket.socket(). 
4. Connect to a server using connect() method. 
5. Send and receive messages using send() and recv(). 
6. End 

Program: 

server.py 
 
import socket 
serv = socket.socket(socket.AF_INET, socket.SOCK_STREAM) 
serv.bind(('0.0.0.0', 8080)) 
serv.listen(5) 
while True: 
conn, addr = serv.accept() 
from_client = '' 
while True: 
data = conn.recv(4096) 
if not data: break 
from_client += data.decode('utf8') 
print (f'From client: {from_client}') 
conn.send("I am from SERVER\n".encode()) 
conn.close() 
print ('client disconnected and shutdown') 

client.py 

import socket 
client = socket.socket(socket.AF_INET, socket.SOCK_STREAM) 
client.connect(('127.0.0.1', 8080)) 
client.send("I am CLIENT\n".encode()) 
from_server = client.recv(4096) 
client.close() 
print (from_server.decode())
